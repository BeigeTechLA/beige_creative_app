CRITICAL security finding.

Plaintext user password persisted to SharedPreferences (lib/auth/login/login.dart:111) alongside the Bearer token (lib/service/shared_service.dart:27). Both leak to logcat via debugPrint(headers) at lib/service/api_service.dart:346 and lib/Profile/myprofile.dart:601. Executive Summary

For CTO / engineering leadership

The codebase is not production-ready. A single root cause — 41 StatefulWidgets talking directly to a concrete ApiService instantiated 58 times across lib/, with no domain layer, no DI, no tests, and no CI — generates downstream failures in every other audited area.

Biggest single risk: the device persists the user's plaintext password and Bearer token in SharedPreferences, and both are written to log output. A single device-side credential extraction yields full account takeover.

Biggest strength: the team picked correct primitives — go_router across 32 sites, modern widget APIs, broad const discipline (1,438 sites), compile-time env split, centralised ApiEndpoints and ColorCode tokens. The foundation supports the rewrite without re-platforming.

This week: stop persisting the password · migrate tokens to flutter_secure_storage · remove the two debugPrint(headers) sites · stand up GitHub Actions running flutter analyze + flutter test per PR.

Findings by Area

#1 / 10

Architecture

2/10

Pattern: none. Flat screens + static service. No domain. No DI. Riverpod dependency is dead — only reference is block-commented in lib/app/app.dart.

  • 58 ApiService() instantiations from widget state
  • Zero abstract class declarations in lib/
  • 4 hard-coded endpoint strings bypass ApiEndpoints
  • SharedService.logout() calls prefs.clear() — nukes all keys
#2 / 10

State Management

2/10

Raw setState. 41 StatefulWidgets · 8 dispose() overrides · 58 TextEditingControllers. Most leak.

  • 266 setState calls / 35 mounted guards (~87% unguarded)
  • fetchprofiledata duplicated in main_screen.dart:50-87 and home_screen.dart:83-124
  • 7 parallel fetchers fire-and-forget in home_screen.dart:314-322
  • Empty catch swallows: shoots_screen.dart:88-90, login.dart:140

Project Structure

2/10

  • lib/auth/view_details_screen .dart — literal space in filename

Security · CRITICAL

CRIT

Plaintext password on disk. Token in logs. Cleartext traffic. Debug-keystore release. No obfuscation.

  • Google Maps key committed twice (google_config.dart:3 + AndroidManifest.xml:24)
